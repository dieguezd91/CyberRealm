# CyberRealm

A 2D top-down cyberpunk RPG with turn-based combat. Explore the city, the bar, the garage and the factory, take on missions and fight your way to Omni-Tech.

## Features
- **Turn-based battle system** (`BattleManager`, moves, characters, random encounters)
- **Quests and mission panel**
- **Inventory, items and store**
- **Dialogue system** and terminal/PC interactions
- **Fast travel** between locations
- **Save/load** through a game data controller
- Patrol enemies and factory hazards (conveyors, pistons)

## Tech
Unity 2021.3.22f1 · C# · Cinemachine · TextMesh Pro

## Run it
1. Open the `Produccion/` subfolder with Unity 2021.3.22f1.
2. Open the `MainMenu` scene and press Play.
